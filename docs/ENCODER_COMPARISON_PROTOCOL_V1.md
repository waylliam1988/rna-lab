# CNN / BiRWKV-Lite / Transformer / EGNN-seed比较协议

任务固定为序列→2D AU/GC/GU配对，使用已核验joint_split_v2训练88/开发验证10条（7个验证组），不读取已经揭盲的旧8条测试。未知位点只在损失和评价遮罩，解码不偷看真值。无1D预训练或旧权重。所有模型共享64维表示、同一序列位置特征/投影、同一对称配对头、距离偏置、阈值0.5及解码规则。

按参数量而非验证成绩选内部宽度，目标150000、差异<1%；具体数量及数据SHA在encoder_comparison_protocol_v1.json。各编码器2个块，25epoch、batch4、lr0.001、AdamW weight_decay0.01、梯度范数1、float32、不用混合精度/编译/dropout，3种子42/43/44。固定最后epoch25，验证曲线仅记录，不选最佳epoch或模型。每种子共享部分初始化相同，训练顺序相同。参数匹配不代表感受野/FLOPs一致。

- CNN：两个残差块，每块两次kernel5卷积，逐层遮罩，完整感受野17。
- BiRWKV-Lite：原Nezha RWKVCellLite双向序列编码、两块、带FFN；不是完整官方RWKV架构。取消状态cap以允许线性前缀递归，decay参数界限[-12,0]，chunk32保持数值稳定。前缀积/和实现已与逐位原cell的输出和梯度对照，padding保持状态、跨样本重置。无专用官方融合CUDA内核，速度结论只对本实现成立。
- Transformer：两块pre-norm、4头全局注意力、FFN宽度按参数匹配，无因果遮罩。
- EGNN-seed：两块稠密全连接图，排除自身/padding边；坐标由序列位置(cos i,sin i,i/128)确定，不使用真实/预测RNA坐标。所有模型都接收相同位置编码信息。图层使用距离和相对序列间隔，更新坐标后以不变量进入特征读出，保证分类路径使用坐标模块。该比较不回答真实3D精修能力。层等变性已测试。稠密边数为N²，不宣称线性复杂度。

质量报告逐序列宏F1/精确率/召回率、按隔离组宏F1、microF1、长度/交叉配对指标、全部种子与标准差。使用观察标签范围，不能解释为全结构或广泛家族泛化。

训练可按种子在三张同型GPU并行，记录实际训练时间/峰值，但公平速度与显存测试另在所有训练完成后、同一cuda:0顺序执行。batch1、长度64/128/256/512，每配置5次预热、20次计时；CUDA同步，分别测GPU网络、网络+CPU贪心解码、前后向/损失/裁剪/AdamW完整更新。峰值allocated/reserved分开报告，包括模型输入及训练时优化器状态，不能与nvidia-smi总显存混为一谈。OOM如实记录，不为单模型改batch。

性能用固定ACGU循环合成输入及合成标签，不能当作预测质量数据；所有模型同形状、同精度。整个配对头仍输出N×N，即使RWKV编码本体近线性，整体显存也不是纯线性。最后检查点严格重载复算，原数据与权重留本地，摘要/配置/哈希公开。

原理参考：[RWKV原论文](https://arxiv.org/abs/2305.13048)、[Transformer原论文](https://arxiv.org/abs/1706.03762)、[EGNN原论文](https://proceedings.mlr.press/v139/satorras21a.html)。这些论文不构成本项目四种定制实现的性能证据。
