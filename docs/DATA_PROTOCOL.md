# 数据协议 v0.1

## 来源

本轮从 MXfold2 官方 v0.1.0 release 获取作者重新打包的三个基准。官方仓库明确提供这些训练/评估数据：https://github.com/mxfold/mxfold2/releases/tag/v0.1.0 。数据的原始来源、适用许可及再分发限制需进一步逐库核查；本地下载不代表获得重新发布授权。

- bpRNA：保留归档里的 TR0/VL0/TS0 划分作为 train/validation/test。不是纯坐标衍生实验标签。
- bpRNA-new：外部测试候选集；逐条提取到独立集合，不用于训练/调参。
- ArchiveII：额外评估候选集；不加入训练。可能与训练集存在同源性，不能当作完全独立的金标准。

未知标签来源保留为 metadata 待核查，而不是伪造 experimental 标志。

## 处理

只读取压缩包成员，不向磁盘解压任意路径。BPSEQ 必须从 1 连续编号、伙伴合法且对称、无自配对。T→U 转换会记录。非 ACGU 的样本保留在标准化数据，但从初版严格基线排除。初版保留 20–256 nt，默认最小配对索引差为 4。

标准化数据保留原始单伙伴配对图（含非 AU/GC/GU、短距边）。严格基线按整条样本排除不支持的标签，不把这些边删除后当作负样本。

同序列同标签合并来源；同序列标签冲突在同一集合内排除并记录。跨集合精确重复按 test_external > test > validation > archiveII > train 的优先级保留，高优先集合不得被低优先集合污染。该优先规则只控制完全相同序列，绝不等价于相似性去泄漏。

输出 JSONL 的 pairs 为 0-based；未知实验条件为 null。observed_mask 仅表示输入 BPSEQ 表格定义的标签位置，不声称这些碱基均直接被实验观察。

## 评估约束

预测使用固定阈值和解码，验证集选参数。测试集不参与训练、早停或阈值选择。报告确切长度过滤、样本数、数据清单哈希。跨家族结论必须等待同源性审计。

完全无配对样本的约定：预测和标签均空时 F1=1；只一方为空时 F1=0。交叉边指存在 i<k<j<l 的配对边，不是对每个碱基的非经典接触分类。
