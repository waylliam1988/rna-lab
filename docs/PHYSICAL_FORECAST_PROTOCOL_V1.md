# 物理观测预测：训练时长与展开长度协议

在任何模型拟合前冻结。只使用three_d_isolated_v1的训练35条序列和开发验证5条；每条按ID选一个实验结构，4个固定哈希种子位置扰动（0.02nm），每个32次原物理积分，得到训练4480/验证640个模拟状态转移。初始坐标的实验证据和模拟辅助标签分别标注；不加入金标准实验标签池。验证仅5个研究/同源隔离组，没有新独立测试。

任务是给定当前3D物理观测，预测下一状态的5维宏观量。原Ghost/NeuralCortex为256/512/8，全量从头训练；新增18→256 Linear+LayerNorm感知适配层，未宣称恢复原GVP。输入为原5维宏观量+13维几何不变量均值，训练池统计标准化；目标使用原smooth-L1反馈变换。J只来自序列AU/GC/GU、间隔≥4的0.1先验，不使用真实终态距离或配对标签。固定温度0、dt0.05；时间不是实测秒数。

阶段三：固定外部展开4步，3个独立种子42/43/44，分别在100、250、500次更新记录。AdamW lr0.001、weight_decay0.0001、batch8、梯度范数上限1。报告全部检查点，不看验证后改超参数。

阶段四：保持上述协议，训练展开8步。既比较相同500次更新，也比较8步250次与4步500次（均16000个输入状态），明确计算量不同。不同展开会改变梯度路径，等输入曝光量并不等于完全相同优化过程。

评估历史4/8/16步均在相同状态16终止，使用相同目标和相同最后观测，避免“后期状态更容易”混淆记忆收益。每个检查点对比原递归状态、逐步清空状态、保持上一观测三种预测。逐通道报告组宏平均MSE，并用Rg/力/能量三项形成动态MSE；两项固定J接触统计不计入动态主指标。先在每组内平均4条扰动轨迹，再平均验证组。

这是teacher forcing条件预测，不是自主生成闭环折叠、真实时间预测或实验轨迹复现。更多轮次不增加家族多样性；模拟器自身正确性不能由模仿它的模型证明。reset是同一训练模型的状态依赖诊断，不替代另行训练的匹配容量无记忆模型。任何阴性/阳性结果均只针对当前协议。
