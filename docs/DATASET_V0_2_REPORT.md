## 标注来源和验证边界

Barnaba 0.1.9在实验坐标上进行几何注释，不使用RNAfold/AI预测结构。工具版本、函数SHA256、RCSB下载URL/时间/CIF SHA256、残基映射和上下文都保存在本地记录中。

与旧bpRNA-PDB归档中相同序列进行239次诊断性比较，可评估范围的平均配对F1一致性为0.9931，199次完全一致。**这不是预测准确率，也不是独立实验验证**：相同序列可能来自不同条件，旧归档的完整溯源仍待核验；该比较没有用于挑选训练标签。

当前仍只有一个配对注释工具，没有多工具共识和局部电子密度验证。6条验证、6条测试远不足以支撑广泛泛化或架构优劣结论。此版本适合检查数据/模型链路和小范围可控实验，`benchmark_ready=false`。
