# 比较序列分析数据如何利用

比较序列分析可以提供有价值的结构监督。它依靠同源RNA比对、进化约束和配对位置的补偿突变等证据，与直接让某个折叠模型输出伪标签不同；但它不保证每条序列的每个配对都经过直接实验验证。

本项目分为三个池：

| 数据池 | 用途 | 是否作为实验真值 |
|---|---|---|
| 直接实验且通过质量审核 | 监督训练、独立验证与测试 | 是，但保留条件与不确定性 |
| 经审核的比较分析 | 可选辅助预训练/辅助配对监督 | 否，必须单独标记 |
| 模型预测/模型补全 | 排除 | 否 |

来源不明的数据留在待审池。bpRNA官方帮助明确说明：非PDB来源使用比较序列分析；但其validation technique字段可能包含“predicted”及算法，也可能是“Unknown”。因此不能将所有101649条非PDB记录一键当成可靠辅助标签。

## 辅助池准入要求

1. 能追溯原数据库条目、文献和结构证据，明确不是RNAfold等模型单独生成的结构。
2. 验证该条序列与共识结构的比对映射，正确处理插入、缺失和不确定位置。
3. 保存家族、同源簇、序列哈希、标签生成方式和验证方式。数据库来源不能替代具体证据。
4. 验证为predicted、带模型补全或来源不清的标签仍排除；没有共变不自动证明配对错误，有共变也不自动证明所有映射边正确。
5. 训练、验证和测试先做同源性隔离；重复结构、相同序列和测试家族近亲不能从辅助池绕回训练。

## 验证使用收益

先建立通过审计的实验基线。之后比较：仅实验数据、辅助池预训练后实验微调、分层联合训练。固定模型与计算预算，使用多个随机种子，在相同实验留出集上比较配对F1、长度/家族分层和置信校准。辅助损失权重由验证集确定，不能假设固定权重天然安全。

当前只是明确数据策略，**尚未批准或启用比较数据训练**。现有训练入口仍只允许通过实验金标准门禁的标签。未来增加显式的辅助数据入口，不放宽金标准门禁。
