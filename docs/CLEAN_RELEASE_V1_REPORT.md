# 实验数据获取与严格清洗发布 v1（2026-10-27）

**版本范围更新：本页保留清洗发布v1的原始计数与training_split_ready=false。后续已复核扩展到176条2D候选，并在joint_split_v2放行88/10/8子集；全量1D池仍未获准预训练。见[逐项验证](STAGED_VALIDATION.md)。不得把本页141条与扩展176条相加。**

本轮形成了 **213,579 条不同完整1D序列**、**141 条带可靠掩码配对监督的不同序列**。这是公开规则下的严格自动筛选可用量，**不是全球实验RNA数据的上限，也不是独立家族数量**。无法核验的记录隔离，不为了数量把不确定标签放行。

**可用证据池尚未等于训练集。** 新池 `training_split_ready=false`：没有联合隔离同源家族、原始研究与构建体/突变库；不能直接用于正式训练或宣称泛化。默认训练入口仍保留旧61条工程验证版本。新旧清洗协议不同，不能把数量直接相加。

两类1D来源精确序列重合为0，也不代表没有同源泄漏：设计库的母本、突变与两端接头仍可能对应2D测试近亲。

2D数量小是本轮范围和严格规则共同造成的。官方复审中有760条链缺独立注释、1,503条链未达到全局配对Jaccard门槛；这些不是已证明错误的数据，而是尚未放行的证据。最终247条链记录经完整序列去重/冲突隔离后得到141条。不能由此推断人类只掌握141条真实2D结构。

## 实际完成的审核

- 覆盖冻结目录的10,522个含RNA实验PDB条目；补下载1,225个缺失官方CIF。原ZIP只作初筛，不靠文件名证明来源。对初筛入选的 1,586 个ZIP来源条目另取官方CIF，结合已有官方文件，共 1,965 个条目重复执行局部质量和注释检查。
- 最终坐标来源下载失败 0 个，最终解析/精审异常 0 个。序列、链/模型/作者编号、插入码、完整原子、占据率、明显键距/平面/冲突、B因子筛选参数、核酸链界面和背景均有可追溯记录。
- 两种几何注释的全局标准配对Jaccard≥0.9，监督标签取交集；分歧、弱/非经典接触、链间/对称性接触及丢失伙伴的端点传播遮罩。同序列冲突或共同覆盖不足的 3 组进入隔离池。**算法共识不是两次独立实验，也不是模型预测准确率。**
- 全部1,024个RDAT：4,545,388 个反应性行，经来源注释、SNR、reads、序列覆盖/突变/编号、误差和缺失掩码审核后保留 344,495 个profile。通过的记录来自 167 个源文件；头部元数据没有发现需进一步分类的预测/模拟声明。没有用 `STRUCTURE` 字段作真值，没有将反应性转成唯一配对图。
- 源站warning、SNR缺失/不足、reads不足、未知试剂等排除计数存在重叠，不能简单相加；逐profile原因保存在压缩审计文件。缺少质量证据不等于原实验错误。
- 审核600个原始RASP轨道容器、981,111,729 个数据行的格式、数值和参考坐标；内部压缩/解析异常 0 个。缺少统一读深、误差、重复实验和转录本映射的轨道仍隔离，**没有计入已批准1D/2D数量**。118个imputed轨道没有请求；两个失败BED另保存三个官方raw BigWig替代包，替代包仍需专项审核。

详细规则见 [FINE_CLEANING_PROTOCOL_V2.md](FINE_CLEANING_PROTOCOL_V2.md)，获取边界见 [INTERNET_ACQUISITION_V1.md](INTERNET_ACQUISITION_V1.md)。FR3D源站快照为2024-11-20；缺独立注释的当前链、修饰/NMR、非经典/链间配对任务和未逐条核验的比较分析辅助池未放行。RASP的数值格式有效不等于完整生物学质量审核。

## 文件与验证

本地发布：

- `data/experimental/clean_release_v1/sequences.fasta`、`sequences.sqlite3`：合并去重1D序列及来源类别。
- `data/experimental/clean_release_v1/paired_deduplicated.jsonl`：2D配对监督、掩码、上下文、来源收据及替代结构。
- `data/experimental/probing_clean_v2/profiles.sqlite3`：实测位置、反应性、误差、掩码、序列和条件注释。中断的v1试跑不用于发布。
- `data/experimental/verified_coordinate_v1/`：官方字节重取、当前坐标重注释与逐链审核；`fine_qc_v1`只是候选阶段。
- `data/manifests/clean_release_v1.json`、`clean_release_validation_v1.json`、`raw_artifacts_v1.jsonl`：可提交的计数、配置/数据指纹、契约检查和官方URL/字节哈希。原始数据、环境、权重不上传GitHub。

契约验证通过：213,579 个序列哈希/字母表/去重、141 个2D记录的来源/掩码/配对边界/单伙伴/界面，以及 344,495 个实测profile全部数组与位置、误差/缺失掩码检查。另有42项单元测试通过；未进行模型训练或预测精度评测。
