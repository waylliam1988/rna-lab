# 可关闭热力学修正接口 v1

第二步完成（2026-10-28）。只新增隔离实验模块，生产训练/预测CLI、CNN结构、损失和标签掩码不变。未开展实验数据训练或验证选参。

公式：`z = CNN_logits + alpha * logit(clamp(P_thermo, 1e-4, 1-1e-4))`。alpha固定，不增加可训练参数；所有条件仍为150019参数。先验完全由序列计算并detach，不读取实验配对或观测掩码。

- alpha=0精确旁路：不查缓存、不做先验算术、不消耗随机数；输出及参数梯度与原CNN逐元素完全一致。
- alpha>0使用按序列哈希核验的先验，矩阵裁剪后对变长batch补齐；标签未知位置仍由原balanced BCE排除。
- 零概率只成为有限负偏置，CNN可以通过足够大的残差覆盖；不把热力学系综的无假结假设变成硬配对禁令。固定alpha不能消除先验的统计偏差，仍需第三步实测。
- 保存模型权重与alpha/epsilon配置，检查点重载精确复现。没有接回J门控/Ghost/RWKV，也没有替换原CNN默认。

验证：5项新测试覆盖alpha零输出/梯度、有限裁剪及可覆盖性、未知标签梯度屏蔽、padding/对称性与重载、非法参数。两条合成序列在cuda:0上分别执行alpha=0/0.25/1的一次优化更新及精确重载，均通过；这只是接口冒烟，不能当预测成绩。全套157项测试通过。结果见data/manifests/thermo_fusion_interface_v1.json。

第三步预定：alpha=0为新训练CNN对照，alpha=0.25为主融合条件，alpha=1为敏感性条件；每组seed42/43/44，同初始化、同组均匀采样顺序、550次AdamW更新、25epoch、batch4、阈值0.5、最终更新检查点。热力学单独预测作为无训练对照。不得根据结果挑alpha、重试种子或改阈值。收益主要以主融合条件是否超过热力学本身衡量；超过旧CNN不等于修正有效。只有10条开发RNA，无独立测试。
