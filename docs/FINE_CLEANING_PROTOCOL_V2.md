# 扩充数据的精细清洗协议

本轮分开处理实验坐标、实测探测信号、基因组轨道、比较分析证据。`quality_verified` 仅表示通过以下公开规则，不表示绝无标注误差。未知条件、无法核验来源或质量、超出任务范围的记录进入待审池；不能据此断言原实验错误。

## 坐标与 2D 标签

1. 冻结当前 10,522 个含 RNA 的实验 PDB 条目，复用原 ZIP 初筛结果，补齐官方 CIF 并重新审核新增/已有官方文件。原 ZIP 的文件名和实验方法字段不能证明官方溯源；入选 ZIP 候选必须从 RCSB 官方单独获取 CIF，再重新执行精细清洗。保留 URL、下载时间、压缩文件哈希和解压后坐标哈希，不重复下载大归档。
2. 分开 label/auth 链名、模型编号、实体序号和作者残基编号/插入码。不混合替代构象。X-ray ≤3.0 Å、EM ≤3.5 Å 为初筛；NMR、修饰、微异质与未知方法隔离，不冒充已审。
3. 每个残基要求完整标准碱基重原子与 C1'，占据率 ≥0.9。掩码排除缺失、非有限坐标、B 因子不在 [0,150] Å²、明显异常的碱基内部/糖苷键距离（1.05–1.85 Å 外）、碱基平面 RMS 偏差 >0.20 Å，以及与其他残基原子距离 <1.0 Å 的严重冲突。B 因子阈值只是本轮保守筛选参数，不等于柔性或局部密度质量。
4. 局部质量覆盖率 ≥95% 后，20–10,000 nt 完整链序列可进入实验关联 1D 池。长度/背景限制不是质量好坏的定义。
5. 2D 范围为20–512 nt。Barnaba 对当前官方实验坐标做几何注释，FR3D 的独立几何注释做交叉检查；二者都是实验坐标衍生注释，不是序列预测，但**两种算法一致不等于两次独立实验**。FR3D 服务器快照为2024-11-20；该来源缺失的链不放入本轮双工具共识池。
6. 只接纳 AU/GC 与 GU 摆动配对；序号间隔 ≥4、一位点至多一个标准伙伴。配对集合在局部可观测范围内的 Jaccard ≥0.9 才继续，最终标签取交集。分歧、非经典/弱接触、对称性接触、跨链接触、映射不明端点遮罩。一个端点失去可用伙伴时同步遮罩另一端，不能把它改成负例。
7. 除FR3D跨链标注外，任何碱基重原子距另一核酸链重原子 ≤5 Å 的位点也保守遮罩，防止历史注释缺失链间配对。复合物背景明确保留；其链内配对不能解释为孤立 RNA 在任意条件下的折叠答案。跨链标签没有被当作链内未配对，也没有被强行转成单链监督。
8. 至少50%位点可监督且至少一对可靠配对。相同完整序列去重，在多个结构/背景的共同可观测位点上若拓扑不一致，整组隔离；一致时保留共同掩码和所有替代来源。存在单RNA链、无蛋白/DNA背景的实验时优先选该背景代表，再按分辨率择优；该类别仍可能含已记录的小分子/离子，不等于无配体的溶液实验。

修饰碱基没有强制映射成标准碱基；NMR、非经典配对、链间配对任务与无独立注释的记录仍保留，供后续专门审核。未获得局部实验密度/约束的重新精修，本轮不能宣称完成了人工结构复核。

## RMDB 实测信号

对全部1,024个 RDAT 文件校验原始哈希，逐文件、逐 profile 保存接受记录及压缩的排除原因明细。`STRUCTURE` 字段不作为实验配对真值。

- 序列来自明确的 per-profile `sequence:`，否则用构建体序列；只有可核验的单点突变格式才从参考序列推导。ACGU/T编码统一、完整保留构建体和两端序列，不用模型补全模糊碱基。
- 依据官方 RDATKit 的 `index = SEQPOS - OFFSET - 1` 映射，检查边界、重复位置和序列一致性。X/N位置标记只用于明确变体序列的索引，不拿它当核苷酸真值。重复 profile、冲突序列、未知突变映射均隔离。
- 源站警告一律隔离；需明确有限 SNR ≥3。若报告 reads，需 ≥1,000；试剂必须属于已实现的实验类型。缺少这些证据是待审，不凭数据库名称自动放行。
- 必须有等长误差数组；有限反应性、有效误差≥0且非缺失哨兵的位置才有实测掩码。至少20个位点可测，源站报告的 SEQPOS 中有效覆盖≥80%。负的背景扣除反应性不自动截成0。
- 覆盖率分母是**报告的实验位点**，不是全长所有碱基；不把DMS等试剂的选择性错误地当缺失，也不由反应性猜出唯一配对伙伴。
- 掩码、原始数值、误差、注释、位置映射和文件哈希保存在 SQLite。按完整序列哈希去重统计1D数量；相同序列的不同条件/重复实验保留为不同 profile。

通过的是严格自动规则下的实验关联序列/信号池。仍须做研究/构建体/家族隔离与训练归一化；不是把约340万条源站坏质量记录或约454万条原始行直接当训练样本。SNR/reads 阈值是本轮筛选政策，不代表不同实验的通用科学界线。

格式依据：<https://rmdb.stanford.edu/deposit/specs/>、<https://github.com/ribokit/RDATKit>。原始参考 parser 文本只在本地来源快照保存，不复制其算法进入项目。

## RASP 与其他来源

RASP 的118个 imputed 轨道未下载。原始轨道逐包检查 SHA256、内部压缩流、行格式、数值/缺失、参考 FASTA 的 contig 和区间边界；分开 proximity contact 与单核苷酸信号。两个不可下载 BED 另留官方 raw BigWig 替代包。

原始 genomic scores 并不自带统一的每序列读深、误差、重复实验与转录本/异构体映射。未完成这些审核的轨道不加入训练，也不虚报成数十万条已清洗序列。BigWig 替代包仍等待二进制轨道审核。BEDPE是区间接触证据，不是精确碱基配对标签。参考基因组和 GFF 是映射资源，不是2D标签。

RNAsolo 的视图存在代表/成员、片段、多链与模型重叠；候选索引不直接当真值，最终2D池以上述官方坐标重注释为准。比较序列分析辅助索引仍单独保留；未完成原始文献/比对证据审核的不计入本轮批准池，不称为伪数据。
