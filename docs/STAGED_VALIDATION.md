# 逐项验证与发布记录

顺序固定：完成一项 → 验证 → 更新文档 → commit/push → 下一项。未开始模型训练时不查看预测成绩；测试集只用于最后固定方案评估。

## 1. 联合隔离：完成

`scripts/build_joint_splits.py` 将141条配对序列按已核验RNA3DB组件、全部替代PDB构建体、primary文献PMID/DOI和局部比对关系合并，再固定seed=42按完整组划分。相似关系要求identity≥0.8且覆盖较短序列≥0.8，包含有两端接头的片段关系。未知同源或不完整primary文献证据隔离。

得到 `joint_split_v1`：train=59、validation=8、test=7，对应2/5/4个完整组；67条2D记录隔离。已检查序列/PDB/文献/组件/组及声明相似关系不跨划分。训练组数量很少，仅适合探索与工程验证，不能宣称广泛泛化。

213,579条1D序列全部登记去向，其中213,505条未核验构建体/研究/同源锚点，继续隔离；训练阶段不使用这部分，也不启动1D预训练。不能因RNA测量质量合格就认为其测试亲缘关系已知。只有已划分的74条2D关联序列继承相应去向。

公开摘要：`data/manifests/joint_split_v1.json`；本地逐序列去向与隔离原因：`data/experimental/joint_split_v1/`。这是一项保守隔离策略，不证明不存在未知远缘同源。后续新增标签若揭示已冻结划分的连接，隔离整个桥接组，不强行放入某一折。

## 2. 注释分歧复核：完成

重新审核150个高质量单RNA链候选，保留原141条严格核心文件不变；新版本将整体Jaccard门槛与逐位点监督可信度分开。扩展池只保留两种几何方法共同支持的配对，所有分歧及失去伙伴端点均遮罩，仍要求至少50%位点可监督及至少一对明确配对；缺FR3D证据仍不放行。该部分明确称为partial-consensus，不冒充全链双工具高一致性。

得到176条不同序列：严格核心141、部分标签扩展35；单RNA链背景49、复合物127，3个冲突序列隔离。原版本没有覆盖或重新命名；新合并视图的共享掩码可进一步收紧。未查看任何模型成绩制定此标签政策。

用第一项已冻结的规则和分配延伸至 `joint_split_v2`：88/10/8条，8/7/4个组；70条因同源/研究证据不足隔离。原来已纳入的序列保持原划分；桥接不同冻结划分的组会整组隔离。已核验标签契约、联合隔离和旧分配保持。当前1D预训练继续关闭。

后续实验协议在任何训练前冻结于 `data/manifests/experiment_protocol_v1.json`：3种子、25epoch、相同优化器/学习率/批次预算，验证集选epoch，测试集封存到所有方案结束；不同参数规模另做按参数量选宽度的静态对照。小样本与不同上下文仍限制结论。
