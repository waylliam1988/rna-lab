# 输入v2：实时几何接触数据

静态消融c28ce14提交推送后，才生成本版本。缓存data/simulated/representation_v2，仅保存两项新增输入；旧gate3数据、标签和权重不覆盖。来源与哈希见data/manifests/representation_v2_geometry_data.json。

按原哈希种子重新积分70个训练/10个验证起点的前8步，将所有原18维观测及最终q/p/xi与旧缓存逐项核对，最大差异均为0。三种未来动作分叉共享执行当前动作之前的历史，新增特征只来自对应时刻q，未读取未来状态或标签。

新特征是原解析场aux的contact_mean与contact_std：在有效且序列间隔≥4的残基对上，以固定J加权sigmoid((1.0nm−距离)/0.1nm)核，形成每残基软接触分数，再计算均值及标准差。标准差保留原代码sqrt(var+1e−8)定义。它不是静态c_mean/c_max，也不是完整三级接触标注；它仍受当前J先验的范围限制。

训练210案例×8帧×2维，验证30案例×8帧×2维；两项在全部案例的时间极差均大于1e−8。仅添加已预注册的输入，原预测目标/损失、J、动作、积分、温度、掩码均不改变，不接J门控。接触平移不变量和位置变化敏感性测试通过。

使用与静态消融相同的完整Ghost/MLP、初始化、采样、500更新、3种子，分别在静态J密度保留/移除条件下提供新增接触。线性基线预测原目标的最近趋势，保持完全相同，不是重新拟合的多变量线性模型。该版本结果只回答当前特征增量及模型条件下的开发收益。
