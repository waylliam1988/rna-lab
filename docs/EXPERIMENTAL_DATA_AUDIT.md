# 实验数据优先审计：2026-10-27

## 用户要求

尽可能广泛获取高质量 1D/2D 数据，排除低质量和其他模型生成的伪标签。严格训练池只接纳可追溯的直接实验证据。原始文件保留，排除不等于删除。

“最多”不能靠把样本、条目、链、重复测量和测量点混为一谈；“最准”也不能只凭数据库名称保证。本轮先建立可核查的数据清单和准入规则，没有声称已获得全部最佳数据。

RNA3DB 的发布 split 只含15441条链，本轮读取更完整的 parse.json，未把上游已经过滤的 split 误当成全库。NMR不是低质量的同义词：本轮将其放入单独的约束/系综质量待审池，而不是用X-ray分辨率标准筛掉。

分辨率阈值是可调整的工程初筛规则，不是普适质量定理。长序列不是低质量；本次证据池没有沿用256nt的训练长度截断。高分辨率也不保证所有残基完整或所有配对正确。

## 原始探测样例中的实际质量问题

- 16SRRNA_H44_0001：41/41个有限测量值，初筛通过。
- ADDRSW_DMS_0001：91/91个有限测量值，初筛通过。
- NEIL1_DMS_0020：82个位置全为NaN，尽管附有STRUCTURE字段，仍拒绝作为有效测量样本。

上述“通过”仅指格式/有限值覆盖检查。试剂适用碱基、背景扣除、信噪比、归一化、重复实验、序列变体映射和条件仍需审核。STRUCTURE字段可能是提交者假设或模型结果，代码明确不把它当配对真值。

## 明确不混入严格标签池的内容

1. RNAfold/Mfold、R2DT、AF或其他模型给出的结构，包括所谓高置信预测。
2. 实验缺失反应性的模型补全值。
3. 仅有家族共识/比较分析、但没有该条序列直接实验支持的配对标签。
4. 只有测量反应性却被计算工具推导成“唯一结构”的标签。
5. 标签来源、坐标映射、提取工具/版本不明，或质量核验未完成的记录。

比较分析不是欺诈或没有价值；只是本次用户指定“直接实验”的严格池不纳入它。人工设计序列如果确实经过测量，也不是伪实验；需要另加 designed 标记，不和天然序列评估混报。

## 下一步的具体顺序

1. 以当前10522个实验PDB条目为候选全集，对照本地PDB_RNA.zip与RNA3DB快照，补齐缺失/新发布条目；避免重复下载本地12GB归档。
2. 逐链核对实体序列、实验方法、局部分辨率/缺失残基/覆盖度、修饰、链间配对和复合物依赖。保留原始实验序列和实际观测序列的映射，不能把缺失残基当未配对。
3. 从实验坐标做几何相互作用注释，记录提取工具版本、阈值和配对类型。坐标注释不是预测未知折叠；但依旧需要标注规则与不确定性审核。检查DSSR授权，或评估开放可复现工具，不自行编造“高精度”提取器。
4. 得到真正的实验配对标签后，按同源簇/家族、PDB实体和序列组划分；条件不同的同序列结构不能随意合并。1D预训练池也需要隔离测试序列，避免跨任务泄漏。
5. 分批下载RMDB原始RDAT，先审核自然RNA与设计库、实验类型和QC元数据。数据量按“不同序列/构建体/条件/测量点”分别报告。RASP/RSVdb作为扩展，先验证未补全版本和下载接口。

这不是启动3D预测训练；利用实验坐标提取2D标签，仍然服务于当前1D→2D任务。
