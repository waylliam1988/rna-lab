# 静态3D联合隔离与接口接入

阶段二，2026-10-27。复用147个官方实验结构记录，与全部176条2D池（包括其隔离记录）联合建图，以RNA3DB已核验同源分量、原始论文、PDB别名、相同序列及局部比对80% identity/80%短序列覆盖连接。未知同源或文献仍隔离；旧测试关联组完全排除。 unresolved 1D构建体仍禁止预训练。

结果：训练54个结构/35条序列/7组，验证10个结构/5条序列/5组；没有可用的新独立测试结构。34条不完整锚点链、34条同源/研究未知、3条碱基平面不足、12条旧测试关联记录隔离。排除理由是按脚本优先级统计，并非互斥物理缺陷总数。未放宽标准来凑数量。

原始实验三锚点不足以代表碱基平面，因此重新从同一哈希核验的CIF提取C4′位置与真实碱基环三原子平面：嘌呤N9/C8/N7，嘧啶N1/C2/N3。同一构象、占有率与B因子筛查，位置Å×0.1转nm，方向单位化。旧CSV代表原子约定并未完全记录，因此不声称与旧坐标语义逐原子等价。平面法线符号由原子顺序规定，原堆叠势对此约定的准确性仍需单独物理验证。

输出data/experimental/three_d_isolated_v1，版本摘要data/manifests/three_d_isolated_v1.json。训练时每条序列选一个按ID排序的代表，避免重复结构加权；其余构象保留用于后续审核。验证脚本检查隔离、哈希、单位法线及全部64个结构的原物理观测/一步积分有限值。两项单元测试检验Å/nm换算、真实平面和构象不混用。

64个结构是静态实验证据；原物理引擎重放生成的下一状态只能标作模拟辅助标签。下一阶段是当前3D状态条件下的世界模型预测诊断，不是序列从头折叠实验。由于没有新测试组，仅报告开发验证结果，不宣称跨家族泛化。旧8条2D测试不复用调参。
