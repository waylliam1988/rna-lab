# 数据优先路线：数据、损失与执行细则 v1

日期：2026-10-27。配套[总路线图](DATA_FIRST_ROADMAP_V1.md)与[执行进度](DATA_FIRST_PROGRESS_V1.md)。本文件补充执行设计，不代表新数据已放行或新训练已完成。不设置负责人、验收人字段。

## 1. 先分清手里的数据

所有任务的输入都包含1D序列；“1D数据”不是另一种模型输入模态，而是指没有可靠配对标签，或只带逐位置观测的记录。

| 数据类型 | 模型输入与目标 | 怎么使用 | 当前边界 |
| --- | --- | --- | --- |
| 已放行实验2D | 序列→实验注释配对边及有效监督范围 | A/B训练、C微调；最终质量评估只用隔离后的实验标签 | joint_split_v2已有88/10/8；旧8条已揭盲，不能充当新盲测 |
| 待审实验2D | 同上，但证据/映射/隔离尚未通过 | 先审计；通过后进入新的版本清单 | 176条候选不是176条已放行训练样本 |
| 比较分析辅助2D | 序列→经审核的共识配对边及监督范围 | 第一轮C的辅助训练阶段 | 单独入口；不能冒充直接实验；目前未就绪 |
| 只有1D序列 | 序列→没有配对目标 | 当前用于来源、去重、家族/构建体与联合隔离整理；可选后续掩码碱基预训练 | 未隔离全池不训练；没有配对图不能生成全0配对标签 |
| 1D实测反应性 | 序列及实验条件→每位置实测反应性 | 后续独立的反应性辅助任务，再检验对2D是否有帮助 | 不从SHAPE/DMS数值推导唯一伙伴；误差、缺失、试剂和条件必须保留 |
| 实验3D及模拟轨迹 | 结构/状态→指定几何或下一状态目标 | 保留原支线，另立协议 | 不进入第一轮A/B/C；模拟转移不是实测配对监督 |

历史清洗发布的213,579条序列、344,495个profile是不同统计单位，也不是当前可直接训练的数量。来源见[CLEAN_RELEASE_V1_REPORT](CLEAN_RELEASE_V1_REPORT.md)。同序列多条件、多重复实验不能当成独立家族；各池不得简单相加。

## 3. 联合隔离和标签格式怎么做

### 3.1 先连关系，再决定去向

1. 同时登记2D、1D序列、profile、辅助候选及历史开发/测试。记录之间的关联有证据来源，不以精确序列不同证明独立。
2. 对预声明必须隔离的关系建立连接图，按连通分量生成`isolation_group_id`。精确重复、母本/突变体、构建体连接不得跨集合；同源/研究关系适用范围须写入具体协议。阈值、工具、版本与人工证据可复查。
3. 同一研究连接大量家族时，报告其导致的大分组，不为凑测试数量拆开。未知关系登记`unresolved`，不能默认独立。
4. 为指标单独冻结`evaluation_group_id`及生物学含义；不能训练后更换分组使宏平均更好看。若与隔离组相同也要明确写出。
5. 所有预训练同样排除开发/测试及规定的关联范围。原已用作开发的目标及其连接不能重新包装成未见测试。

### 3.2 标签至少区分正、负、未知

实验记录沿用`sequence/pairs/observed_mask`的语义；新增辅助记录还需保存`label_type/source_receipt/mapping/review_status/isolation_group_id`及显式的配对级监督范围。

- `positive_pairs`：证据支持的配对边，索引统一0起始，边只登记一次i<j；验证范围、对称性及单伙伴。
- `negative_pairs`或等价可审计的负标签生成规则：只包含证据允许视为负的位置对。
- `unknown`：没有监督；不因为没有列入正边就变成负边。
- 序列位置映射、实验覆盖、标签有效范围分别保存。比对缺口不是碱基，不插入假碱基或伪标签。

**现有`collate`的限制：** 它把两个`observed_mask=true`端点之间所有兼容候选对视为已知正/负，再用`pairs`置正。这适合现有冻结标签定义，不能直接承载“只知道若干正边、其余未知”的辅助记录。新入口必须支持配对级mask；不能只给全true端点mask来复用旧入口。新辅助入口同时保存端点覆盖与配对级mask，保证评价也能识别未知边。

部分正边的记录若没有任何可靠负监督，单独标记`positive_only`：可保留作证据，但不直接纳入第一轮二分类A/B/C。仅优化正边容易使所有候选分数上升；若要使用必须另设正例/未标注学习协议，不能悄悄改变第一轮损失。

首批最多20条候选只用于验证来源审核、映射和隔离流程，不是正式训练的样本量验收门槛。试点报告须统计通过数量、独立隔离组/研究覆盖、有效正负监督量、长度和标签覆盖；据此说明是否足以开展有解释力的预算内比较。审核满20条不自动放行A/B/C；覆盖不足时先归档可行性结论，再决定按新版本规则扩充或停止，不降低准入标准。

## 4. 2D具体用什么损失

第一轮沿用当前CNN的**带掩码、逐RNA正负类平衡的二元交叉熵**，不切换MSE，不添加Ghost状态预测、反应性或物理损失。

模型输出`z[b,i,j]`为配对logit，`y`为0/1；只有mask=true的位置参与。候选范围沿用AU/GC/GU、j-i>=4、排除padding和未知。每个无向配对只计上三角，不能重复计算对称位置。

```text
P_r = 有效正边集合；N_r = 有效负边集合
L_pos(r) = mean(softplus(-z_ij)), (i,j)属于P_r
L_neg(r) = mean(softplus( z_ij)), (i,j)属于N_r
L_pair(r) = mean(存在的类损失项)
L_batch = mean(有有效监督的RNA的 L_pair(r))
```

正负两类都有时，各占1/2；只有可靠负标签而无正边时使用负类项并单独计数；两类都无则从可训练清单拒绝。当前函数会跳过无监督样本，新入口须在运行前拒绝，避免静默改变有效batch。第一轮辅助准入排除positive_only是新增设计约束，不能宣称旧函数已经实现。

这等价于在有效位置分别计算`binary_cross_entropy_with_logits(..., reduction='none')`再按上述规则聚合。训练直接使用logit，不能先sigmoid再传给with_logits。不要直接改成所有N×N位置的普通平均，也不额外叠加`pos_weight`、Focal/Dice或负采样；那些会改变参照，需另设因素实验。[PyTorch BCE说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html)。

辅助阶段只用审核辅助2D计算L_pair，微调阶段只用实验2D计算同一定义的L_pair；本轮不混池联合加权。辅助阶段正负证据覆盖仍需分别报告，不能以相同损失名称掩盖标签语义不同。

## 5. 1D以后如何用：两个独立分支

以下是预先写清的候选方案，**目前没有启用，也不与第一轮辅助2D同时叠加**。

### 5.1 只有序列：掩码碱基预训练

- 先完成同一套联合隔离。输入是带特殊MASK token的序列，目标为被遮位置原本的A/C/G/U四分类，不是配对矩阵。
- 首版候选：对15%的有效碱基独立抽样并全部替换为MASK；padding不选、不损失。无位置被选时重新采样一个有效位置。四类交叉熵只在被遮位置计算，先逐序列平均再batch平均。
- 必须新增独立MASK token及预测头；当前token=4是padding，不能拿它兼作MASK。掩码率、token实现、位置抽样及采样器在训练前冻结。
- 只迁移共享编码部分；配对头保持对应种子的同一随机初始权重。若扩大embedding，记录权重映射与padding/MASK行处理，不能加载后错位。
- 对照随机初始化配对训练、预算匹配的仅配对训练、序列预训练后配对微调。分别报告更新数、碱基曝光、实际算力；两种任务一次更新成本不同。先看预训练目标是否优于训练集碱基频率基线，再看实验2D开发收益。
- 任务可学不证明2D受益。当前CNN有限上下文可能限制该任务效果；失败先记录，不自动扩大模型。

### 5.2 实测反应性：连续值回归

- 输入为序列及已审核的试剂/实验条件；目标为对应条件下实测逐位置数值。无反应性标签的2D记录不补0，无配对标签的profile不计算配对损失。
- 先选一个试剂/相容处理协议的来源试点，保留原值与单位/归一化说明，不把不同量纲profile直接混成目标；记录母本、重复及条件分组。
- 首版候选：训练数据拟合位置值的整体均值和标准差，`scale=max(train_std,1e-6)`，目标标准化后用masked Huber(delta=1)。每profile先对有效位置平均，再按预声明构建体/重复抽样规则聚合。原始单位结果一并报告。
- 数据若不满足可比尺度或缺少试剂/处理说明，继续隔离，不用逐profile真值标准化来掩盖不可比性。所有缩放参数只从训练集估计，开发/测试固定应用。
- MSE可作回归诊断指标或另立损失对照；首版不同时搜索MSE/Huber直到得到阳性。Huber的阈值与归一化一起冻结。[PyTorch Huber说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.modules.loss.HuberLoss.html)。
- 误差数值先用于审核和分层报告，首版不直接使用1/error²加权，避免误差接近0导致极端权重。
- 先验证反应性预测相对训练均值及碱基/试剂均值基线的收益；报告masked MAE/MSE、每profile及组级结果。全缺失profile拒绝。
- 若随后进入多任务：`L=L_pair + lambda*L_reactivity`，每项独立归一化，分别记录；lambda与两类batch比例必须冻结。无标签项不计算；整批无对应标签时不伪造目标。推理2D只输入序列，实测反应性不能被用作隐藏输入。
- 先进行反应性辅助训练后微调，可避免同时确定lambda；联合多任务是再下一项独立实验。是否采用哪条路线须在该分支协议明确，不能运行中切换。

## 6. 第一轮A/B/C如何冻结到能启动

目前只冻结设计，以下候选默认值在数据审计与资源冒烟后写入正式JSON；未经冻结不运行正式实验。

| 项目 | 明确规则 |
| --- | --- |
| 模型/精度 | 固定约150k CNN，float32；不新增模块，不用AMP/编译 |
| 种子/初始权重 | 42/43/44；每种子A/B/C初始完整state_dict一致并记录SHA256，全部从随机初始化开始 |
| 优化器 | 候选沿用AdamW，lr=0.001、weight_decay=0.01、gradient_clip=1；恒定lr，无正式搜索 |
| batch | 候选batch4、无梯度累积；长度上限及超长处置按审计结果冻结；不能静默裁剪序列或把跨裁剪伙伴当负边 |
| 预算 | A=U；B/C=Ua+Uf；U、Ua、Uf待审计后填整数。旧88条、batch4、25epoch对应550次更新仅作预算参考，不自动视作新实验预算 |
| 阶段边界 | B前段实验Ua、后段实验Uf；C前段辅助Ua、后段实验Uf。B/C在边界都重建AdamW、同lr；保留模型权重，重置优化器状态 |
| 抽样 | 候选组均匀→组内序列均匀，固定种子、有放回，凑满固定batch；A/B/C实验阶段规则相同，辅助按其审核组执行；记录实际曝光与组权重 |
| 计步 | 仅optimizer.step成功算更新。A/B/C实验阶段单独记录有效正负边、碱基、样本、组及重复曝光；不把同更新称为同FLOPs |
| 检查点 | 固定最终更新，不按开发最优挑选；每50更新及阶段终点记录开发诊断，不因此提前选权重 |
| 主比较 | 每种子C-B，先逐RNA F1→组内平均→组间平均。开发集、分组及标签范围三条件完全相同 |
| 推进门槛 | 训练前填写delta绝对F1阈值、严重退步阈值及具体规则；未填则不能启动。不能看结果决定最小收益 |
| 运行上限 | 正式3条件×3种子=9次。技术失败最多每配置重试1次，保留首个失败与修复原因；协议改变则新版本，原运行不删除 |

基础资源冒烟只使用已放行训练记录，至多每条件一个种子、5次更新，不评价新测试；不计为正式效果证据。若发生OOM，不单独为某条件改batch，先停止并统一修订协议。

冒烟使用独立于正式预算的短阶段：A执行5次实验更新；B执行2次实验更新后重建AdamW，再执行3次实验更新；C执行2次辅助更新后重建AdamW，再执行3次实验更新。B/C后段使用相同实验采样序列。验收须覆盖阶段标记、切换时保留模型权重、清空优化器状态、学习率与更新计数，以及最终检查点独立重载；新辅助入口和阶段切换未通过时，不进入正式运行。冒烟权重、优化器及采样状态不得接续为正式运行，正式运行从冻结初始状态重新开始。

C在辅助训练后必须接实验微调；不能拿辅助开发最优检查点与B最终检查点比较。B/C相同种子的Uf段使用同一实验采样序列，以减少后段曝光差异。

### 评价细节

- 固定sigmoid分数、阈值0.5、贪心单伙伴解码、AU/GC/GU及最小间隔4。先对完整序列解码，再按有效标签范围评价；不能用真值mask帮模型避开未知端点竞争。
- 实验金标准仍沿用冻结的端点mask规则；部分辅助标签如需诊断，使用其配对级mask，只解释监督范围内结果，不当全结构F1。
- 无有效候选标签的RNA不参与主指标并记原因/数量；不能因预测差而排除。有效范围内真值与预测均空时F1=1，一方非空另一方空时F1=0，沿用现有`pair_metrics`。单独报告空真值数量与非空真值子集指标，避免空样本掩盖结果。
- 上一条的无监督排除是待实现的新评价规则：当前`evaluate`会统计全部记录，尚未检查有效候选标签数。S3须在模型推理前按冻结标签规则生成评价准入清单，排除无任何有效候选标签的记录，保存ID、原因及逐组数量；无有效记录的组不纳入宏平均并报告，所有组均无效时停止评价。它不同于有可靠负标签但无正边的RNA，后者仍可参与评价。增加全未知、无合法候选、仅可靠负标签及组内全部排除的契约检查，复核指标分母；不得在结果出来后按模型表现排除样本。历史报告与原评价定义保留，新旧范围不同的分数不得直接当作同口径收益。
- 全部种子逐组差值都保留；多数组改善以种子平均后的每组C-B>0计算，平局不算改善。严重退步组单独列出，不只报总均值。
- 新测试没有形成时只提交开发报告。测试可用时冻结访问清单，配置确定后一次评估所有预声明条件/种子，不挑最好种子。
- 独立进程重载最终权重、配置和数据指纹复算；最终配对列表一致，指标容差预声明。先保存日志与哈希，再汇总。

### 8.1 定义与归一化

对RNA r的每条可靠正边(i,j)，取共享端点i的可靠负伙伴集合N_i。候选须满足当前任务AU/GC/GU、最小间隔及非padding规则；配对级mask明确为负才能加入。对称访问上三角标签时，先规范化无向索引，不丢失端点的左侧伙伴。

```text
d_k = z[i,k] - z[i,j]，k属于N_i
ell_i = logsumexp(concat([0], d))
对j端同样计算ell_j
RNA竞争损失 = mean(该RNA内有可靠正边且有可靠负候选的端点ell)
batch竞争损失 = mean(有适用端点的RNA竞争损失)
总损失 = 当前逐RNA平衡BCE + lambda * batch竞争损失
```

用logsumexp实现，禁止先exp后求和以免溢出。没有适用端点的RNA不进入竞争均值，但照常进入BCE；整个batch没有适用端点时竞争项为设备/类型正确的0，保留BCE反向路径。分别记录两项均值及各自分母，不把缺失竞争项当作所有端点零误差。

首版使用全部可靠负候选，不做top-k/难负采样；logsumexp仍随候选数变化，不声称消除了长度影响，按长度与负候选数报告。未知、非经典、链间及超范围伙伴不得因竞争项被推成负边。positive_only记录仍不按本轮二分类协议自动放行。

该项训练相对排名，不能保证对称匹配、单伙伴或全局最优，继续使用同一对称配对头与贪心解码。现有BCE已经平衡正负，不再叠加额外pos_weight；其输出仍称分数。

### 8.2 实现前后的必要检查

- 手工小矩阵核对公式、左右侧伙伴索引、正负mask；提高真伙伴logit或降低可靠负候选logit应降低对应竞争项。
- 极端正负logit下损失及梯度有限；未知候选改变不影响竞争项；改变padding不影响结果。
- 无正边、无负候选、全batch无适用端点均有明确结果；不能产生NaN或跳过应有BCE更新。
- lambda=0时，在相同输入、权重与随机状态下，总损失及梯度与原BCE一致；新代码不得无意改变参照组。
- 单RNA重复组批平均一致；无向边虽然仅保存一次，正边两端均可参与竞争，分母准确。
