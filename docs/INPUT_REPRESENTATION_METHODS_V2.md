本分类按特征计算依赖定义，不把“5个宏观通道”当作完整输入。依赖动态状态的特征在某条轨迹上也可能偶然恒定；静态量则在本实验固定J、序列及掩码时按定义恒定。旧数据/模型定义保持冻结。

## 额外状态与已知条件

- 8维动量/温控摘要是动态状态摘要，不是完整分子相空间。守恒或特殊轨迹下某些分量也可能恒定。
- 动作是当前已知、未来窗口内恒幅的径向控制条件，历史帧动作标记为0。
- 预测间隔是查询条件，不是观测到的未来状态。
- v2预留观测索引18/19，加入实时几何接触均值/标准差：取原解析场aux的contact_mean/contact_std、contact_rc=1.0nm、原序列间隔和掩码规则。它们依赖当前q及J；不等同于静态J密度，不将标准差改名为最大值。

原J、物理积分、单位逆质量、温度、动作方案全部不变；不接回能量驱动J门控。几何接触是目前已核查、未显式输入的一类动态摘要，不声称是唯一遗漏的动态信息。

## 固定预测目标与析因对照

保持原3个动态预测目标（Rg/力/能量的归一化宏观变化量），不增加接触预测辅助损失，避免把输入收益与新监督信号混淆。固定原35条训练/5条隔离开发验证，840/120个模拟查询、未来1/4/8/16步、500更新、batch16、3种子及原Ghost核心。5个开发组不是新独立盲测，不能据此宣称普遍跨RNA泛化。

2×2输入条件：静态J密度索引1/2保留/移除 × 新几何接触18/19不提供/提供。各条件分别独立训练完整Ghost与当前时刻MLP，并保持同一线性趋势基线。先完成无几何接触的静态消融、提交推送，再生成v2几何接触并完成另外两组。

为严格匹配输入层宽度、参数量和初始化，观测统一20维。移除的列在训练池标准化后置0，表示模型不接收该样本的特征值；保留占位不保留信息。每个种子同种架构各条件使用完全相同初始参数、同一查询采样顺序和预算。完整输入为20+8+1+1=30维。MLP总参数按Ghost选宽度；不声称有效容量/FLOPs完全相同。

全部统计只用训练池，动态变化量缩放与旧gate3一致。主汇总量预先固定为四个未来间隔等权平均的按组标准化动态MSE；同时报告逐间隔、逐种子、逐组及相对线性Skill，不挑最好间隔。输入增益按成对相对误差下降报告；“未检测到收益”不等于统计等价。所谓较一致收益至少需三个种子同方向、五个验证组中至少四组同方向，仍只能作为开发证据。
