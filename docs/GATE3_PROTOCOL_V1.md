# 第三关：冻结的因果诊断协议

拟合前冻结，三个独立种子42/43/44分别使用三张GPU；不合并显存。每种子7个独立训练模型，各500次AdamW更新、batch16、lr0.001、weight_decay0.0001、梯度范数上限1。不按验证挑轮次/模型/种子。原Ghost核心256/512/8；新增感知条件和残差输出包装明确属于诊断适配层。

数据：35条训练序列各2个哈希固定扰动起点、5条开发验证各2个。零动作预热8步，保留8步历史；同一q/p/xi分叉出径向力幅度−0.4/0/+0.4，幅度在未来窗口保持，方向随当前位置径向定义。训练70锚点、210分叉案例/840个未来间隔查询，验证10锚点、30案例/120查询。未来间隔1/4/8/16全部报告。查询数不是独立RNA样本数。

所有缓存位于data/simulated/gate3_v1，明确标作模拟辅助信号；官方实验起点仍由three_d_isolated_v1追溯，不修改金标准。全部240个当前状态接口检查和全部30个验证分叉重放通过，另外重放一个训练三分叉；已核验组间隔离。构造反例中同q、不同p的当前18维观测相同，8步后宏观量最大差0.0465941，证明此观测表示可能缺少状态信息，不是自然RNA实验中的效应测量。

训练模型：

- Ghost：观测；观测+动量摘要；观测+动作；观测+动量摘要+动作。
- Ghost独立控制：完整条件，但每步只清空RWKV的num/den，保留连续控制mem/aux，区分RWKV记忆与Ghost自身状态。此项在任何拟合前加入，旧数据生成协议原件另存gate3_data_generation_protocol_v1.json；数组不变，训练协议记录修订理由。
- 两个独立训练的当前时刻MLP：观测；完整条件。宽度只按对应Ghost总参数量选择，差异<1%。Ghost含原总线/目标参数，其中部分没有参与此预测路径；同时记录有梯度张量的参数量。相同总参数量不代表相同有效容量/FLOPs。

四种条件Ghost和RWKV控制在每种子共享相同初始Ghost权重；输入投影分别初始化，不加载旧Nezha权重。MLP独立初始化。动量输入是8维摘要（均速度、位置/方向速度RMS、Rg变化率、温控量），不是完整分子动量。动作只在当前帧输入，之前为零；它表示已知未来恒幅控制方案，不提供未来观测。

预测Δ宏观量，除以训练池逐未来间隔/通道标准差（下限1e−5），不减目标均值；零输出等于持久性。仅训练动态通道0/3/4。输入观测与动量标准化只用训练池。共同基线：持久性、最近速度线性外推、训练组平均变化量。

每个Ghost还做保留当前帧的固定历史打乱、每步清空全部状态诊断；完整模型额外测试去掉动量、去掉动作、在相同起点三分叉内轮换动作。它们是分布外干预诊断，独立训练的信息消融才是主要对照。单独评价±动作分叉的预测差异，和“动作无效”的零差异基线比较。

报告逐通道MSE、按组宏平均的标准化动态MSE/Skill、超过数值容差的变化方向命中率、逐组结果、动作效应误差。三个种子全部报告，检查点严格重载复算。仅5个验证组，没有新盲测，不声称实验折叠或广泛泛化。若没有收益也保留全部结果，禁止看结果后更改本协议。
