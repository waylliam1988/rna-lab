# 下一步：真正的比较监督来源试点

2026-10-28。此文件是有边界的执行计划，不是正式训练协议；本次只完成入口盘点，没有选择或放行家族、下载比对、训练或评价。当前默认CNN＋balanced BCE，既有止损和旧test限制不变。

## 为什么调整工作重点

现有非PDB候选索引101649条：CRW55600、RFAM43273、RNP466、SPR623、SRP959、tmRNA728。全部validation_technique/publication/contains_model_predictions字段为空。index_comparative_candidates.py本来就将这些字段设为None，并没有逐条审定它们是模型伪标签。因此0准入表示待审，不能当成101649条被证伪。真实盘点及文件SHA见data/manifests/comparative_metadata_inventory_v1.json。

不再把“补齐少量PDB文献键”当成扩充辅助池的唯一路径。那些工作仍有来源审计价值；另行启动真正比较分析来源的家族级小试点，先验证标签链路可行性。

## 辅助池应要求什么，不应混淆什么

- 实验评估池仍要求通过本项目直接实验证据与标签质量门禁。
- 比较辅助池要求可追溯家族/原文结构证据、比对、映射、标签范围和同源隔离。可以在明确规则下继承经核验的家族来源证据，不要求每条天然序列独立解析过3D，也不把比较共识改名为实验真值。
- 若家族共识来自RNAfold/MFOLD/RNAalifold且无法区分可靠比较部分，按用户要求隔离；官方数据库名、PMID存在或人工编辑本身不保证无模型标签。
- 对只有可靠正边的记录，保存positive-only证据，但不伪造负标签来满足当前A/B/C。是否另做正例/未标注学习是另一协议，不自动开展。
- 同一个家族的一千条序列可以增加该家族监督覆盖，不算一千个独立评估目标。辅助训练也不能绕过开发/测试家族/clan关系隔离。

官方来源语义：[Rfam家族构建说明](https://docs.rfam.org/en/latest/building-families.html)。2026-10-28核对该页成功；bpRNA帮助页本次访问超时，未据此臆造条目验证方式。
