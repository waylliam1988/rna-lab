# 辅助监督与独立评估：有限可行性核查 v1

日期2026-10-28。本次只复核已有本地聚合审计及少量官方/作者网页，不下载数据归档，不读取模型预测，不修改标签/划分，不批准新样本。结论是存在值得审核的资源路径，但“足够且合格”的数量尚未证实。

## 本地证据不能被解释成资源穷尽

- joint隔离池70条有直接实验坐标、来源与质量证据；64条缺已核实同源组件、9条study完整性不足、6条缺study ID，缺口可重叠。它们缺独立性证据，不是已证明标签伪造。
- clean_release相对joint的67条非精确序列候选分为42个当前关系组；39组未发现当前连接但独立性证据不全。39组不是39个已合格独立家族，也不是可准入下限。
- 全141条clean_release中52条目前未发现已知连接但证据不全；这些数字与70条是不同口径，不相加。
- 名为comparative-source-feasibility-v1的既有20条试点来自bprna_pdb_candidates_NOT_GOLD，evidence_class为reported_pdb_derived_pairing。它并不是对Rfam等比较分析来源进行的代表性试点，不能以该试点0准入推断所有比较监督均不可得。

依据：data/manifests/joint_quarantine_audit_v1.json、data_first_clean_release_eval_candidate_audit_v1.json、data_first_comparative_pilot_v1.json。

## 两条外部候选路径

### A. 实验评估候选：Archive-NoFam

作者2026年论文描述从实验PDB结构整理Archive-NoFam，最终89条链、47个结构差异组；补充材料S1含结构说明，S2含参考二级结构及预测结果。它是可核查的评估候选来源，不能未经检查继承为本项目的新盲测，也不能把47组直接当成本项目47个独立生物学组。

下一步若开展该来源可行性审核：先获取出处与entry/chain候选清单，优先复用已有坐标；对照本项目全部当前/历史数据检查序列、家族/组件、原研究、构建体及评估暴露。只提取参考标签与证据，不查看附带模型预测来选样本；检查其标签是否与本项目AU/GC/GU、最小间隔、链间端点、缺失掩码定义兼容。人工设计但实验测定的RNA不等于模型伪标签，须单列天然/设计构建体背景。无Rfam匹配也不是独立性证明。

来源：[论文全文](https://rnajournal.cshlp.org/content/32/4/428.full)、[补充材料目录](https://rnajournal.cshlp.org/content/32/4/428/suppl/DC1)。本次核实作者描述和目录，未下载或逐条审核补充数据。

### B. 辅助配对候选：经原文核实的Rfam SEED子集

Rfam官方提供家族SEED多序列比对和共识二级结构，并记录SE/SS来源字段；但官方明确说明结构可来自实验/比较证据，也可来自MFOLD、RNAfold、RNAalifold，PMID字段本身不能区分。因此整库不符合本项目排除模型伪标签的要求；只有逐家族原文与结构来源审核后的子集才可能成为辅助池。

进入可行性审核时先选一个原始文献和比对可定位的家族，检查原文结构依据、具体支持边、序列到比对列映射、缺口/不确定位置及同源家族/clan关系。显著共变可作支持证据，但不能补成未经支持的完整配对图；只有正边而无可靠负边时不进入现有首轮二分类A/B/C。必须先排除开发/测试及其声明关联范围，不以同一家的许多序列冒充许多独立组。

来源：[Rfam官方家族构建说明](https://docs.rfam.org/en/latest/building-families.html)。本次只核实来源语义，未选定合格家族、下载比对或放行训练。

## “足够”如何判定

不能预先承诺几百条就够，也不能由88条直接断言统计上不可能。实际可用量须经过上述来源/标签/关系筛选。足够应对照预声明目标：希望检出多大的组级改善、组间误差差异多大、最终留下多少独立组。若做精度/效力规划，仅用开发或合理假设并报告敏感性，不先查看新测试成绩。

首先需要交付来源级可行性报告：辅助有效正/负/未知边、通过组数和研究数；评估通过组数、长度/背景覆盖与全部排除原因。A/B/C只有辅助标签与链路门禁通过才启动。即使新评估可用而辅助池仍不可用，也可另立CNN迁移诊断问题，不假装已回答辅助监督收益。

当前决定：不是资源已穷尽，也不是已经获得足够数据。优先有限检查上述两个来源，保持既有准入为0与所有止损规则；是否扩大获取由来源审核结果决定。本次没有新样本被准入。
