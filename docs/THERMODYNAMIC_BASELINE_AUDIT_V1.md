# 热力学基线与CNN互补审计 v1

执行日期：2026-10-28（Asia/Taipei）。第一步完成；仅访问冻结 train88 / validation10，没有打开旧 test。

使用全局 ViennaRNA 2.7.2 Python API 的 RNAfold 配分函数引擎；Turner2004、37°C、1.021M 单价盐、dangles=2、最小发夹环3；孤立单链、无配体/蛋白/Mg特异结合模型。这是固定计算假设，不是实验缓冲液推断。完整设置、参数文件哈希、98个序列缓存索引哈希见 protocol/summary manifest。配对概率是计算输入特征，不是新增实验监督。

调用现有 evaluate：AU/GC/GU、序列距离>=4、阈值0.5、单伙伴贪心，允许交叉边；先在完整序列上解码再掩码未知端点。训练损失掩码未更改。标准无假结系综的边缘概率不会被误当成强制无交叉解码规则。
