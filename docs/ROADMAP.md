# 研究路线与进入下一阶段的条件

## 0：数据与可复现底座（当前）

下载官方 ArchiveII、bpRNA、bpRNA-new 归档；生成来源清单和清洗报告。保留官方划分，先消除完全相同序列的交叉污染。每条记录保存来源、原始路径、标签方法、序列哈希、配对列表、观测掩码、未知条件。

下一步是补齐各来源的家族/同源簇，开展适用于核酸的相似性与覆盖度聚类。不能直接把蛋白默认参数照搬到核酸。先聚类再划分，同时审计官方测试集与所有训练来源的关系。

进入下一阶段条件：解析统计可解释、标签契约明确、划分冻结；数据管道回归测试通过。

## 1：最小 2D 基线

当前实现为小 CNN 编码器 + 对称 pair scorer + 贪心匹配解码。先运行短序列验证 loss 与独立指标，之后加入 RNAfold 等外部基线；没有安装时不得伪造结果。

训练/验证按固定协议；报告逐序列宏 F1、整体微 F1、长度分层与交叉边指标。冻结方案后才查看测试集。使用多个随机种子，不以单次最好结果为结论。

## 2：分步更新

结构状态 P_t 为软配对分数；更新器根据序列表示与当前 P_t 计算 delta，允许增加和撤销配对。先测试 1/2/4/8 个计算步，检查振荡、收敛、步间质量变化与额外开销。

最终标签只约束结果；无中间态标签时，不强制每一步 F1 单调增加。中间最优分数只能用于诊断，不能用真实标签在推理时挑选步骤。

## 3：Ghost 与 RWKV

- Ghost：调节更新门控和步幅；状态显式传入/返回，每个 RNA 必须重置，不能跨样本泄漏。
- RWKV：记忆更新轨迹；有监督预测下一状态/动作结果后，才评估是否可称为世界模型。由当前更新器生成的轨迹只是算法轨迹，不是实验动力学。
- 对照：静态基线、普通迭代、迭代+RWKV、迭代+Ghost、完整组合。匹配参数量、计算预算与训练预算，报告至少三个种子和效率。
- 旧实现的参考快照不参与基线导入；避免把全局 Config 和隐藏状态耦合迁入。

进入下一阶段条件：增益在固定验证协议和多种子下稳定；计算成本可接受；消融能解释贡献。

## 4：实验探测和条件输入

单独引入 SHAPE/DMS 观测头与掩码损失，不把反应性硬转为配对真值。区分 sequence-only 预测与 probing-assisted 推断，后者不可与前者直接比较。温度、离子和 pH 保留缺失标志；先查数据覆盖度，再决定是否建模。

## 5：共转录过程，最后才是 3D

用真实 nascent RNA / cotranscriptional probing 数据验证前缀结构与重排。不用最终配对裁剪冒充真实过程。不宣称计算步对应毫秒。多候选先用固定 K、校准和覆盖/冗余指标验证；之后再决定是否接 3D。

每个阶段允许失败；若 Ghost 没有稳定增益，保留研究实现和实验结果，不用继续堆模块掩盖问题。
