# 拟合门槛：有限lr扫描

先完成EGNN几何审计c2e5c31：坐标/距离存在，padding正确、坐标更新进入分类路径；没有发现需要修复的上述错误，模型源文件保持不变。位置种子不是RNA几何，仍保留该任务边界。

按用户要求只扫描Transformer、EGNN-seed、BiRWKV-Lite。每种四变体：1e−4、1e−3、3e−3，以及1e−3+warmup。Warmup仅固定一种：前10%优化器步（55/550）线性从base/55升至base，然后保持，不再单独搜索。除此之外保持约150k参数、2块、25epoch、batch4、AdamW weight_decay0.01、clip1、相同训练池/解码/阈值、同种子初始化及打乱顺序；不改LayerNorm/图边/坐标/配对头/损失。

继续原三种子42/43/44，合计36个有限训练作业，不是完整超参数网格。仅加载88条训练RNA，只报告训练loss/F1、全部配置及最终epoch25。每5epoch和epoch1记录训练曲线，不按曲线挑最佳epoch。验证/测试文件不加载，也不进行新的速度比较。原CNN检查点只在训练集复算作为参考，不重新扫描CNN。

判断分开报告：

1. 用户止损点：若三个编码器各自全部成功完成的最终运行均<0.8，则停止调优，报告未充分拟合；非有限/失败运行单独列明，不给失败编造分数。
2. 验证比较验收：每种编码器需有一个共同变体让三个种子最终训练F1全部≥0.9，CNN原参考也需满足，才重新开放验证集比较。若不满足，本次不看验证、不再追加扫描。达到门槛是减少训练程度混淆的必要检查，不是所有泛化差异只能由架构造成的充分证明。
3. 若存在≥0.8但没有全部达到0.9，严格“全部<0.8”止损条件未触发，但验收门槛仍关闭；照样在用户规定扫描结束后停下，如实报告，不能借此自动扩大调参。

“未达到拟合门槛”不等于完全未学习：此前三者已有训练F1约0.46–0.71。最终结论限定为当前默认实现、三个lr、一个固定warmup和25epoch，不再将验证分数差异称为架构优劣证据。超参数扫描协议与源SHA见encoder_lr_scan_protocol_v1.json；结果和检查点分别留公开摘要及本地runs。
