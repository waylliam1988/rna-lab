# 下一次从这里继续

先读 [最新发布报告](CLEAN_RELEASE_V1_REPORT.md)、[精细清洗协议](FINE_CLEANING_PROTOCOL_V2.md)、`data/manifests/clean_release_v1.json` 和 `data/experimental/POLICY.json`。

1. **联合冻结1D/2D划分。** 按可核验同源证据、相似序列/片段、原始研究、构建体和突变库合并组。先隔离测试家族/构建体，再从1D预训练池排除其近亲；不能只对2D测试序列精确去重。未知同源记录继续隔离，报告独立组数及家族、长度、来源分布。
2. **建立固定预算的简单基线。** 先用已冻结的单RNA链、无蛋白/DNA背景范围验证CNN/轻量序列编码器到配对头、标签掩码与解码；复合物背景单独实验，保留小分子/离子条件。测量pair precision/recall/F1、假结与长度分层、时间和显存，多种子复核。热力学模型作独立对照，不生成训练真值。新2D池只含AU/GC及GU摆动，不能声称覆盖所有非经典配对。
3. **逐项接入研究机制。** 普通显式结构状态迭代 → RWKV → Ghost，各自消融，固定划分、参数/计算预算与评估流程。计算步数不当作真实物理时间，不用最终配对图的前缀裁剪充当共转录中间态。

可继续的数据扩展：修饰/NMR专门质量协议；缺少独立注释的链；链间配对任务；RASP原文、读深/误差、重复实验、转录本/异构体映射和BigWig审核；比较分析辅助池的原文与比对证据。待审项不能通过扩大数量绕过审核。

原61条 `paired_v0_2` 保留作工程链路验证。新池尚未划分，不能直接替换训练默认路径后宣称泛化提升。

暂不开展：3D、隐离子反演、强化学习、真实时间动力学解释、超大语言模型预训练。
