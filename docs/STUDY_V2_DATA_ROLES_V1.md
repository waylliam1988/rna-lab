# 下一轮研究v2：数据角色与结论边界

2026-10-28。用户明确授权重新定义下一轮研究的数据角色，继续遵守防泄漏和标签质量原则。研究ID：rna2d_auxiliary_study_v2。承接旧试点收尾4d4f6fd；本版本是新规则与角色清单，不回写旧划分、旧成绩或旧准入决定。

## 1. 这一轮要回答什么

开发问题：在规定的实验开发组上，经审核比较监督＋实验微调，是否比相同阶段/更新预算的纯实验训练产生一致、值得继续研究的配对预测收益？固定约150k CNN＋balanced BCE，主要比较C-B，保留A原预算参照。

目前可以建立有边界的开发实验，不把它包装为跨所有RNA家族的普遍泛化。新的独立实验测试尚不存在；独立泛化结论仍须新证据。新测试缺失不必阻止全部工程/开发试验，但会明确限制结论。

## 3. 哪个限制变化了，哪些继续保留

变化：与已退役历史评估家族有关联，不再单独构成v2训练候选的永久否决。以后若将其中数据或近亲用于训练，旧测试与旧论文基准数字只能作为历史参考，不能用来证明新模型的独立泛化。

保留：所有训练、辅助和预训练都排除当前活动开发/未来活动测试及其预声明关系范围：精确重复、构建体母本/突变/片段、已知family/clan/同源，以及相关原始实验研究和重复结构。来源、质量、映射、条件/复合物背景、正负未知范围继续审核；模型预测/补全标签继续排除。未找到阳性关系不等于隔离已通过。

数据库论文、综述和方法论文的“来源引用”，与某次实验的primary-study关系分开登记。不能因为许多家族都引用同一数据库介绍就自动合并全库，也不能漏掉它们确实共享的原实验/构建体来源；引用语义不明时保留待核。

比较辅助可继承经审核家族证据，不要求每条天然序列独立测过结构；它仍是辅助监督。若只支持正边，先标positive-only，不能按当前二分类方案把其他边全部设负。

## 4. 三个Rfam家族如何处理

RF00001、RF00005、RF00010旧试点的排除与停止结论保留，旧记录没有错。v2只移除“退役历史评估关系本身”这一项永久否决，不自动通过三族：

- 5S、RNaseP已有文献/数据库来源支持，仍需当前共识的映射、边级标签/可靠负范围和活动开发集关系审核。
- tRNA的当前SEED谱系/来源仍有未核项，必须继续保留，不能用角色重定义覆盖来源缺口。
- 既有精确/组件筛查没有发现三族与当前10条开发记录的阳性连接，但这没有覆盖全部family/clan/原实验/构建体关系。因此三族的活动隔离状态均为unresolved，不是“已清白”。

当前没有新增代表、标签或训练准入。下一步是在v2规则下完成这三族与活动开发组的明确关系表，再按通过家族选最多5条代表做映射。若发现活动留出关联，照样阻断，不为释放来源把当前开发集搬到训练。

## 5. 新评估怎么建立

先限定评估问题：已见家族中的新构建体，还是未见同源组迁移。v2确认性目标优先独立同源/构建体/原研究组；不能把两种问题混成一个“泛化分数”。

在接触候选模型新测试表现之前，登记全部来源及历史暴露、核对质量与标签范围、检查与所有训练/预训练/开发材料的关系，按完整组保留并冻结候选名册、分组和访问规则。仅因论文叫“独立测试”或无Rfam命中不能继承独立性。

Archive-NoFam只是待审来源之一；本次不下载或选定其成员。若某候选已用于开发或与开发/训练存在不合规关联，则不能进入新测试。若未来新证据连接已冻结角色，停止并记录冲突，新版本处理；不能静默改split或将已揭盲结果重新变盲。

没有合格新测试时，明确test_count=0，照实报告开发实验；不能用增加种子或重抽旧测试取代新的独立组。

## 6. 结论分三级

| 证据 | 最多可支持的表述 |
| --- | --- |
| 数据/接口/冒烟契约通过 | 任务与训练链路可运行，不能说预测有效 |
| 固定开发集上的全种子/逐组C-B结果 | 在本协议和这些开发组上有/无推进价值；不是无偏独立泛化证据 |
| 方案确定后按协议评估新独立实验组 | 在声明任务、证据范围和这些组上得到独立验证；不外推整个RNA折叠问题 |

不得使用CNN旧训练F1高证明泛化；不以一两个平均分数宣称学到物理过程；不以小样本未过推进门槛证明方法普遍无效。组数、覆盖和不确定性与指标一起报告。

## 7. 落地与验收顺序

1. 本次：冻结角色政策、生成带旧/新角色的只读清单，保留原始文件指纹并验证保护优先规则。
2. 随后：重审当前三族的活动留出关系、来源和监督范围；只是候选，不启动训练。活动隔离未解决则保持隔离。
3. 有合格候选后：建立新的数据/标签manifest，验证pair-level mask、无有效监督记录/组的分母、阶段切换及最多5更新冒烟。旧CLI不能直接装入新辅助记录。
4. 冻结正式A/B/C的数据、种子、整数预算、阶段优化器重置、采样、最终检查点、delta及严重退步规则，再训练；不恢复旧扫描或伙伴竞争调优。
5. 确认性评价另立访问协议；没有新独立测试就停在开发结论。

新角色判断工具独立于旧生产入口；原train_baseline.py和旧POLICY.json没有被改成“允许所有旧测试训练”。角色清单不是可直接供训练器消费的新版数据集，也不是操作层准入白名单。J门控仍关闭，未启用1D全池预训练。
